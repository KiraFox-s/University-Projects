Spirit Fox: Forest Escape is a small 2D adventure game developed as part of a web development course. 
The game is built with JavaScript and Phaser 3 and takes place in an enchanted forest where the player controls a spirit fox.
The player can move around the forest using WASD, collect magical crystals to earn points, and use spirit flames to defeat shadow enemies. 
Different crystals provide different amounts of points, while defeated enemies also increase the player's score.
The project demonstrates basic game development concepts such as player movement, keyboard input, collision detection, interactive objects, enemy movement, projectiles, scoring, and asset management. 
The game also includes custom visual assets for the player, enemies, magical crystals, projectiles, and the forest environment.
Technologies: JavaScript, Phaser 3, HTML5, CSS/HTML, and Git/GitHub.
