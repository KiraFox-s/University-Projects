# TV Show Search App

An interactive and responsive web application for searching and displaying TV shows using the TVmaze API.

## Features

- Search for TV shows using the TVmaze API
- Display search results dynamically with JavaScript
- Show TV show images, titles and summaries
- Responsive layout for desktop and mobile devices
- Mobile-specific styling using CSS media queries
- Google Fonts (Roboto)
- Bootstrap navbar and responsive components
- URL query parameters for API requests

## Technologies

- HTML
- CSS
- JavaScript
- TVmaze API
- Bootstrap
- Google Fonts
- REST API
- URL query parameters
